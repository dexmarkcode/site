The branch-current method of Chapter 3 works, but it is wasteful. Give it a circuit with eight branches and it hands you eight simultaneous equations, most of which are trivial and serve only to cancel each other out. Nodal analysis is the cure. It reduces the number of unknowns to the number of nodes minus one, it produces equations with a beautifully regular structure, and it is the method that circuit simulators such as SPICE use internally. If you learn only one systematic method thoroughly, make it this one.

:::objectives
- Choose a reference node and define node voltages.
- Write KCL equations in terms of node voltages for circuits containing resistors and current sources.
- Write the conductance matrix of a resistive circuit by inspection.
- Handle voltage sources using direct substitution and the supernode technique.
- Apply nodal analysis to circuits containing dependent sources.
- Use Millman's theorem for parallel branches.
:::

## The idea

Choose one node as the **reference**, or ground, and give it a potential of 0 V. Every other node gets an unknown **node voltage**, measured relative to the reference. The key insight is that once every node voltage is known, *everything* is known: the voltage across any element is the difference between the voltages at its ends, and the current through any resistor follows from Ohm's law.

So instead of solving for branch currents, we solve for node voltages, writing one KCL equation at each non-reference node. Each resistor current is expressed directly in terms of node voltages:

$$ current from node j to node k through <i>R</i> = (<i>v</i><sub>j</sub> − <i>v</i><sub>k</sub>)/<i>R</i>  || 4.1

That one substitution is the whole trick. KCL plus Ohm's law, combined at the outset, gives one equation per node instead of one per branch.

## Choosing the reference

Any node can be the reference, and the answers for voltage *differences* and currents do not depend on the choice. But a good choice makes the algebra simpler. Prefer the node with the most elements connected to it, or the node attached to the negative terminal of the main voltage source. In many practical circuits there is an obvious "ground" or chassis node, and it makes sense to use it.

## The basic procedure

1. Choose the reference node and label the other node voltages *v*<sub>1</sub>, *v*<sub>2</sub>, …
2. At each non-reference node, write KCL: the sum of currents *leaving* through the resistors equals the sum of currents *entering* from current sources.
3. Express every resistor current using Equation 4.1.
4. Solve the simultaneous equations.
5. Use the node voltages to find whatever currents, voltages or powers were asked for.

The convention in step 2 — resistor currents written as leaving the node — is a matter of taste, but it has a big advantage. If you assume every resistor current flows *out* of the node you are writing the equation for, you never need to think about directions: the term is always (this node − other node)/*R*. Some currents will then be negative in reality, but the algebra takes care of that automatically.

{{fig:t04_nodal|A two-node circuit. The 3 A source feeds node 1; the 1 A source draws current out of node 2.}}

:::example Two nodes, two current sources
Find *v*<sub>1</sub> and *v*<sub>2</sub> in Figure 4.1.

*Node 1:* *v*<sub>1</sub>/4 + (*v*<sub>1</sub> − *v*<sub>2</sub>)/2 = 3.

*Node 2:* (*v*<sub>2</sub> − *v*<sub>1</sub>)/2 + *v*<sub>2</sub>/6 = −1. The right-hand side is negative because the 1 A source draws current *out* of the node.

*Tidy up.* 0.75*v*<sub>1</sub> − 0.5*v*<sub>2</sub> = 3 and −0.5*v*<sub>1</sub> + 0.667*v*<sub>2</sub> = −1.

*Solve.* The determinant is 0.75 × 0.667 − 0.25 = 0.25. Then *v*<sub>1</sub> = (3 × 0.667 − 0.5)/0.25 = 6 V and *v*<sub>2</sub> = (−0.75 + 1.5)/0.25 = 3 V.

*Check at node 2.* (3 − 6)/2 + 3/6 = −1.5 + 0.5 = −1 A. Correct.
:::

## The conductance matrix by inspection

Look again at the tidied equations in that example. They can be written in matrix form as **G v** = **i**, where **G** is the **conductance matrix**:

| | *v*<sub>1</sub> | *v*<sub>2</sub> |
|---|---|---|
| Node 1 | 1/4 + 1/2 | −1/2 |
| Node 2 | −1/2 | 1/2 + 1/6 |

The pattern is completely general for circuits made of resistors and independent current sources:

:::key
- Each **diagonal** entry *G*<sub>kk</sub> is the sum of all conductances connected to node k.
- Each **off-diagonal** entry *G*<sub>jk</sub> is minus the sum of conductances connected directly between nodes j and k.
- Each entry of the **source vector** is the total current injected into that node by current sources.
:::

With practice you can write the matrix equation straight from the diagram without writing any KCL equations at all. The matrix is always symmetric for such circuits, which provides an instant check. A lost minus sign or a misplaced conductance usually breaks the symmetry and shows itself straight away.

For larger circuits, the matrix form is the natural way to hand the problem to a calculator or computer. Most scientific calculators will solve a 3 × 3 system directly, and any programming language with a linear-algebra library will solve a 300 × 300 one.

## Voltage sources

Voltage sources complicate things slightly, because the current through an ideal voltage source is not determined by its voltage. There is no "*v*/*R*" term to write for it. There are two situations.

### Voltage source connected to the reference

If a voltage source has one terminal on the reference node, the node at its other terminal is no longer unknown: its voltage *is* the source voltage. That removes one unknown and one equation. This is the easy case, and it is why choosing the reference at the negative terminal of a voltage source is such good practice.

A voltage source in series with a resistor can also be converted into a current source in parallel with that resistor (a source transformation, covered properly in Chapter 6). In nodal analysis it is often simplest just to write the resistor current as (*v*<sub>node</sub> − *V*<sub>s</sub>)/*R*, which has the same effect.

### Voltage source between two non-reference nodes: the supernode

If a voltage source sits between two nodes, neither of which is the reference, we cannot write KCL at either node individually, because we do not know the current through the source. The solution is to draw a closed surface round both nodes *and* the source, forming a **supernode**, and write KCL for the whole surface. The source current is then internal to the surface and does not appear.

That gives one equation for two unknowns. The second equation comes from the source itself: the difference between the two node voltages equals the source voltage.

{{fig:t04_super|A voltage source between two non-reference nodes. Nodes 1 and 2, together with the source, form a supernode.}}

:::example A supernode
In Figure 4.2, find *v*<sub>1</sub>, *v*<sub>2</sub> and the current through the 6 V source.

*Constraint:* *v*<sub>2</sub> − *v*<sub>1</sub> = 6.

*KCL for the supernode:* the 4 A entering must leave through the two resistors: *v*<sub>1</sub>/2 + *v*<sub>2</sub>/4 = 4.

*Substitute:* *v*<sub>1</sub>/2 + (*v*<sub>1</sub> + 6)/4 = 4, so 0.75*v*<sub>1</sub> = 2.5 and *v*<sub>1</sub> = 3.33 V. Then *v*<sub>2</sub> = 9.33 V.

*Source current.* Now apply KCL at node 1 on its own: the source carries 4 − 3.33/2 = 2.33 A from node 1 to node 2. As a check, the 4 Ω resistor carries 9.33/4 = 2.33 A.
:::

## Dependent sources in nodal analysis

The rule from Chapter 3 still applies. Write the nodal equations treating the dependent source as if it were independent, then add an equation expressing its controlling variable in terms of node voltages. Substitute and solve.

There is one visible consequence: the conductance matrix is **no longer symmetric**. A dependent current source controlled by the voltage at node 1 but injecting into node 2 adds a term to row 2, column 1, with no matching term in row 1, column 2. Don't let this alarm you. It is the mathematical fingerprint of a non-reciprocal device, and transistors and amplifiers are very much non-reciprocal.

:::pitfall
When a dependent source's controlling variable is a *current*, express that current in terms of node voltages before substituting. For instance, if *I*<sub>x</sub> is the current downward through a 5 Ω resistor from node 2 to the reference, write *I*<sub>x</sub> = *v*<sub>2</sub>/5. Forgetting this step leaves you with more unknowns than equations.
:::

## Millman's theorem

A common practical arrangement is a set of branches all connected between the same two nodes, each consisting of a voltage source in series with a resistor: batteries in parallel, generators feeding a common busbar, or several sensor outputs summed through resistors. Nodal analysis with a single unknown gives the common voltage at once:

$$ <i>V</i> = Σ(<i>E</i><sub>k</sub>/<i>R</i><sub>k</sub>) / Σ(1/<i>R</i><sub>k</sub>)  || 4.2

This result is known as **Millman's theorem**. A branch containing only a resistor is included with *E* = 0, contributing to the denominator but not to the numerator. The formula is simply a weighted average of the source voltages, weighted by conductance, which gives a very useful intuition: the busbar voltage is pulled most strongly towards the source with the lowest internal resistance.

:::tip
Millman's theorem shows something examiners like to probe. When batteries of slightly different voltages are connected in parallel, the weaker one may be *charged* by the stronger, wasting energy and possibly damaging the cells. Always check the sign of each branch current.
:::

## When to choose nodal analysis

Nodal analysis is usually the better choice when:

- the circuit has fewer nodes than meshes;
- the sources are mostly current sources;
- you need voltages rather than currents;
- the circuit is not planar (cannot be drawn without crossing wires), since mesh analysis requires a planar circuit.

It is also the method of choice for circuits containing operational amplifiers, because the ideal op-amp's constraints are naturally expressed as node-voltage relationships.

## A disciplined layout

The arithmetic of nodal analysis is straightforward. The errors come from untidiness. For every problem in this chapter:

1. Redraw the circuit and circle every node.
2. Mark the reference node with a ground symbol.
3. Label each unknown node voltage.
4. Mark any supernodes clearly.
5. Write the equations, one per line, with every term in the same "leaving the node" form.
6. Solve, then check KCL at a node you did not use, or at the reference node.

It feels slow at first. Within a dozen problems it will feel natural, and you will make far fewer mistakes than you would by rushing.

:::summary
- Nodal analysis uses node voltages as unknowns: one KCL equation per non-reference node.
- Resistor current from node j to k is (*v*<sub>j</sub> − *v*<sub>k</sub>)/*R*.
- For resistors and current sources, the conductance matrix can be written by inspection and is symmetric.
- A voltage source to the reference fixes a node voltage directly; one between two other nodes creates a supernode.
- Dependent sources add one control equation each and make the matrix asymmetric.
- Millman's theorem gives the common voltage of parallel source–resistor branches as a conductance-weighted average.
:::
