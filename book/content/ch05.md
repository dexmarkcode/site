If nodal analysis is KCL organised into a system, mesh analysis is the same thing done for KVL. Instead of node voltages, the unknowns are **mesh currents**: imaginary currents that circulate round each window of a planar circuit. The method is the natural choice when a circuit has more nodes than meshes, when its sources are mainly voltage sources, or when the quantity you want is a current. Engineers who work with power networks, motor drives and audio crossovers tend to reach for it first.

Learning both methods properly is worth the effort. They are duals of one another, and each one makes the other easier to understand. Moreover, the ability to choose the shorter method for a given circuit can halve the time a problem takes in an examination.

:::objectives
- Define mesh currents in a planar circuit and write KVL equations in terms of them.
- Write the resistance matrix of a resistive circuit by inspection.
- Handle current sources on the outside of a circuit and between meshes (the supermesh).
- Apply mesh analysis to circuits containing dependent sources.
- Decide whether nodal or mesh analysis is the better choice for a given circuit.
:::

## Mesh currents

A **planar** circuit is one that can be drawn on paper without any wires crossing. Its meshes are then the "window panes" of the drawing. To each mesh we assign a **mesh current**, conventionally clockwise, which circulates round that mesh only.

Mesh currents are not always physical branch currents. A branch on the outer edge of the circuit belongs to one mesh only, so its current equals that mesh current. A branch shared by two meshes carries the *difference* of their mesh currents. For example, if mesh 1 flows down through a shared resistor and mesh 2 flows up through it, the actual current downward is *I*<sub>1</sub> − *I*<sub>2</sub>.

This automatically satisfies KCL at every node. Each mesh current enters a node and leaves it again, so the bookkeeping is done for us. All that remains is to write one KVL equation per mesh.

## The basic procedure

1. Check that the circuit is planar and identify its meshes.
2. Assign a clockwise mesh current to each mesh.
3. Walk clockwise round each mesh, writing KVL: source rises equal resistor drops.
4. For a shared resistor, the drop in the direction of travel is *R* times (this mesh current − neighbouring mesh current).
5. Solve the simultaneous equations, then recover branch currents and voltages.

Step 4 is the mesh analogue of the "leaving the node" convention in nodal analysis. Write every shared-resistor term as (my current − your current) and you will never need to think about directions.

:::example Two meshes
Find the mesh currents in Figure 5.1, and the power taken by each source.

*Mesh 1:* travelling clockwise, we rise 10 V through *V*<sub>1</sub>, then drop 2*I*<sub>1</sub> across *R*<sub>1</sub> and 3(*I*<sub>1</sub> − *I*<sub>2</sub>) across *R*<sub>2</sub>. So 10 = 2*I*<sub>1</sub> + 3(*I*<sub>1</sub> − *I*<sub>2</sub>), or 5*I*<sub>1</sub> − 3*I*<sub>2</sub> = 10.

*Mesh 2:* travelling clockwise, we drop 1 × *I*<sub>2</sub> across *R*<sub>3</sub>, then pass through *V*<sub>2</sub> from + to −, a drop of 5 V, then drop 3(*I*<sub>2</sub> − *I*<sub>1</sub>) across *R*<sub>2</sub>. There are no rises, so 0 = *I*<sub>2</sub> + 5 + 3(*I*<sub>2</sub> − *I*<sub>1</sub>), or −3*I*<sub>1</sub> + 4*I*<sub>2</sub> = −5.

*Solve.* The determinant is 5 × 4 − 9 = 11. *I*<sub>1</sub> = (40 − 15)/11 = 2.27 A and *I*<sub>2</sub> = (−25 + 30)/11 = 0.455 A.

*Branch current.* *R*<sub>2</sub> carries 2.27 − 0.455 = 1.82 A downward.

*Powers.* *V*<sub>1</sub> delivers 10 × 2.27 = 22.7 W. The mesh-2 current enters the + terminal of *V*<sub>2</sub>, so *V*<sub>2</sub> absorbs 5 × 0.455 = 2.27 W. The resistors absorb 10.3 + 9.92 + 0.21 = 20.5 W, and 20.5 + 2.27 = 22.7 W. Balanced.
:::

## The resistance matrix by inspection

Writing the two mesh equations from that example in matrix form gives **R i** = **v**:

| | *I*<sub>1</sub> | *I*<sub>2</sub> |
|---|---|---|
| Mesh 1 | 2 + 3 | −3 |
| Mesh 2 | −3 | 3 + 1 |

and the right-hand side is (10, −5). Once again there is a rule that lets you write the matrix straight from the diagram:

:::key
- Each **diagonal** entry *R*<sub>kk</sub> is the total resistance round mesh k.
- Each **off-diagonal** entry *R*<sub>jk</sub> is minus the resistance shared by meshes j and k (when both currents are clockwise).
- Each entry of the **source vector** is the sum of the source voltages round that mesh, counted positive when they push current clockwise.
:::

The matrix is symmetric for circuits containing only resistors and independent voltage sources. For a ladder network each mesh shares resistance only with its immediate neighbours, so the matrix has a characteristic "tridiagonal" pattern of non-zero entries along the leading diagonal and its two neighbours. Recognising that pattern is a quick check that you have not attached a resistor to the wrong mesh.

## Current sources

Current sources are to mesh analysis what voltage sources are to nodal analysis: slightly awkward, because the voltage across an ideal current source is not determined by its current. Again there are two cases.

### A current source on the outside of the circuit

If a current source lies in a branch that belongs to only one mesh, it fixes that mesh current directly. Make sure you get the sign right: if the source pushes current anticlockwise relative to your clockwise mesh current, then the mesh current equals minus the source value. That mesh is now known, and you need no KVL equation for it.

### A current source shared by two meshes: the supermesh

If a current source sits in a branch shared by two meshes, neither mesh can be written on its own. The fix is the exact dual of the supernode. Form a **supermesh** by mentally removing the current source and its branch, and write KVL round the larger loop formed by the two meshes together. The second equation comes from the source itself: the difference between the two mesh currents equals the source current.

:::example A supermesh
A 12 V source drives a 2 Ω resistor in the left-hand mesh. The middle branch, shared by both meshes, is a 2 A current source pushing upward. The right-hand mesh contains a 4 Ω resistor and a 2 V source whose + terminal is at the top, so that it opposes clockwise current. Find the mesh currents.

*Constraint.* Mesh 1 flows down through the middle branch and mesh 2 flows up it, so *I*<sub>2</sub> − *I*<sub>1</sub> = 2.

*Supermesh.* Round the outside: 12 − 2*I*<sub>1</sub> − 4*I*<sub>2</sub> − 2 = 0.

*Solve.* Substituting *I*<sub>1</sub> = *I*<sub>2</sub> − 2 gives 10 = 2(*I*<sub>2</sub> − 2) + 4*I*<sub>2</sub> = 6*I*<sub>2</sub> − 4, so *I*<sub>2</sub> = 2.33 A and *I*<sub>1</sub> = 0.333 A.

The voltage across the current source, which the supermesh deliberately ignored, can be recovered afterwards: walking up the left mesh, it is 12 − 2 × 0.333 = 11.3 V, top positive.
:::

:::pitfall
When you form a supermesh, do not include the resistor that happens to sit in series with the current source in your KVL equation. You have removed that entire branch. Its voltage is part of the unknown voltage across the current source, and the current through it is fixed anyway.
:::

## Dependent sources

Exactly as before: write the mesh equations treating the dependent source as independent, then add one equation expressing its control variable in terms of mesh currents. A controlling current in an outer branch is simply the relevant mesh current; one in a shared branch is a difference of mesh currents. The resistance matrix becomes asymmetric, and that is expected.

Dependent sources sometimes make a circuit look harder than it is. A current-controlled voltage source whose controlling current is the mesh current through it behaves exactly like a resistor, positive or negative. A voltage source of value 5*I*<sub>1</sub>, placed in mesh 1 and opposing *I*<sub>1</sub>, adds 5 Ω to that mesh's diagonal entry. Spotting such simplifications saves time.

## Nodal or mesh?

For any given circuit, count the unknowns each method needs:

- **Nodal:** (number of nodes − 1), minus one for each voltage source connected to the reference.
- **Mesh:** (number of meshes), minus one for each current source on an outer branch.

Choose whichever gives fewer, unless the question asks for a particular quantity that one method delivers more directly. If you need a single voltage between two nodes, nodal analysis gives it at once; if you need a single branch current, mesh analysis may be quicker. If the counts are equal, choose the one you are more comfortable with, since accuracy matters more than elegance.

Remember too that mesh analysis only works for planar circuits. A circuit that cannot be drawn without crossing wires has no well-defined set of meshes, and nodal analysis is then the only systematic option.

:::tip
In examinations, a short sentence justifying your choice of method ("This circuit has three meshes but only two unknown node voltages, so nodal analysis is used") costs ten seconds and shows the examiner that you are working deliberately. It also forces you to count, which occasionally reveals that the method you were about to use is the longer one.
:::

## A note on solving the equations

By this stage you will regularly be solving three simultaneous equations by hand. Learn one reliable method thoroughly. Cramer's rule is tidy and easy to set out; Gaussian elimination is quicker for larger systems and less prone to arithmetic slips with awkward numbers. Most scientific calculators have an equation-solving mode, and you should certainly use it to check your work. In an examination, though, write down the matrix equation clearly before reaching for the calculator, so that the method marks are secure.

The problems in this chapter start with two-mesh circuits and progress to three-mesh ladders, supermeshes, dependent sources and a full mesh analysis of the Wheatstone bridge. That last one is worth doing carefully: it shows how much more work mesh analysis can be than Thévenin's theorem for the same answer, which is a nice motivation for Chapter 6.

:::summary
- Mesh analysis uses clockwise mesh currents as unknowns: one KVL equation per mesh. It applies to planar circuits.
- A shared branch carries the difference of its two mesh currents.
- For resistors and voltage sources, the resistance matrix can be written by inspection and is symmetric.
- A current source on an outer branch fixes a mesh current; one shared by two meshes creates a supermesh.
- Dependent sources add a control equation and make the matrix asymmetric.
- Choose between nodal and mesh analysis by counting unknowns.
:::
