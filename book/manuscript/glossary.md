Alternating current (AC)
: Current that periodically reverses direction. UK mains alternates at 50 Hz.

Ammeter
: An instrument for measuring current, connected in series. An ideal ammeter has zero resistance.

Ampere (A)
: The unit of current: one coulomb per second.

Branch
: A single two-terminal element in a circuit, such as a resistor or source.

Bridge network
: A network of four arms with a fifth element connecting their midpoints; it cannot be reduced by series and parallel steps alone unless balanced.

Conductance (G)
: The reciprocal of resistance, measured in siemens (S).

Conductor
: A material with many free charge carriers, such as copper, through which current flows easily.

Conventional current
: Current imagined as a flow of positive charge, from the + terminal of a source round the circuit to the − terminal.

Coulomb (C)
: The unit of charge; about 6.24 × 10^18^ electrons.

Current divider rule
: In a parallel group, current divides in proportion to conductance: I~x~ = I~T~G~x~ / G~T~.

Delta (Δ) connection
: Three elements connected in a closed triangle between three terminals; also called a π network.

Dependent source
: A source whose value depends on a voltage or current elsewhere in the circuit; used to model transistors and amplifiers.

Direct current (DC)
: Current that flows steadily in one direction.

Efficiency (η)
: The ratio of useful output power to input power.

Electromotive force (EMF)
: The open-circuit voltage of an ideal source within a real source model.

Equivalent resistance
: A single resistance that draws the same current as a network at a chosen pair of terminals.

Essential node
: A node at which three or more branches meet.

Ground (earth, reference node)
: The node chosen as 0 V, from which other node voltages are measured.

Ideal current source
: A source that delivers a fixed current regardless of the voltage across it.

Ideal voltage source
: A source that maintains a fixed voltage regardless of the current drawn.

Insulator
: A material with very few free charge carriers, through which current flows very poorly.

Internal resistance
: The resistance inside a real source that causes its terminal voltage to fall as current is drawn.

Kirchhoff's current law (KCL)
: The total current into a node equals the total current out of it.

Kirchhoff's voltage law (KVL)
: The algebraic sum of the voltages round any closed loop is zero.

Linear circuit
: A circuit whose responses are proportional to its sources and add when several sources act together.

Load
: The component or circuit that receives power from a source.

Loading
: The change in a circuit's behaviour caused by connecting a load or measuring instrument to it.

Load line
: The straight-line terminal characteristic of a linear source, plotted to find the operating point of a non-linear device.

Loop
: Any closed path through a circuit that does not pass through a node twice.

Matched load
: A load whose resistance equals the Thévenin resistance of the source, giving maximum power transfer.

Mesh
: A loop that contains no other loop within it.

Mesh analysis
: A systematic method using circulating mesh currents as unknowns and KVL as equations.

Millman's theorem
: The common voltage of parallel sources with series resistances is the conductance-weighted average of their EMFs.

Node
: A connection point in a circuit, including all the wire joined to it.

Nodal analysis
: A systematic method using node voltages as unknowns and KCL as equations.

Norton's theorem
: Any linear two-terminal network is equivalent to a current source in parallel with a resistance.

Ohm (Ω)
: The unit of resistance: one volt per ampere.

Ohm's law
: For a linear resistor at constant temperature, V = IR.

Open circuit
: A break in a circuit; an infinite resistance through which no current flows.

Parallel
: Elements connected between the same two nodes, sharing the same voltage.

Passive sign convention
: A labelling rule in which the reference current enters the + terminal of an element, so that P = VI is the power absorbed.

Potentiometer
: A resistor with a sliding contact, used as an adjustable voltage divider.

Power (P)
: The rate of transfer or conversion of energy, measured in watts (W).

Preferred values
: The standard series (E6, E12, E24…) of resistor values.

Resistance (R)
: Opposition to the flow of charge, measured in ohms.

Resistivity (ρ)
: A property of a material describing how strongly it resists current, measured in ohm metres.

Series
: Elements joined end to end at a node with nothing else connected, carrying the same current.

Short circuit
: A path of (ideally) zero resistance, across which there is no voltage.

Source transformation
: The replacement of a voltage source in series with a resistor by a current source in parallel with the same resistor, or vice versa.

SPICE
: A family of computer programs that simulate circuits, principally by nodal analysis.

Star (Y) connection
: Three elements connected from a common centre to three terminals; also called a T network.

Supermesh
: A loop formed by two meshes that share a current source, used in mesh analysis.

Supernode
: A region enclosing two nodes joined by a voltage source, used in nodal analysis.

Superposition theorem
: In a linear circuit, any response is the sum of the responses to each independent source acting alone.

Thermistor
: A resistor whose resistance changes strongly with temperature.

Thévenin's theorem
: Any linear two-terminal network is equivalent to a voltage source in series with a resistance.

Tolerance
: The permitted deviation of a component's actual value from its marked value.

Volt (V)
: The unit of potential difference: one joule per coulomb.

Voltage divider rule
: In a series chain, voltage divides in proportion to resistance: V~x~ = V~S~R~x~ / R~T~.

Voltmeter
: An instrument for measuring voltage, connected in parallel. An ideal voltmeter has infinite resistance.

Watt (W)
: The unit of power: one joule per second.

Wheatstone bridge
: A bridge circuit used to measure resistance by balancing two voltage dividers.
