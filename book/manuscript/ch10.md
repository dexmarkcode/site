In 1973 a group at the University of California, Berkeley, released a computer program called SPICE. It could take a description of almost any electronic circuit and calculate every voltage and current in it. Half a century later, descendants of SPICE are used to design virtually every chip, circuit board and power supply on the planet. Many of them are free, and you can run one on your laptop this afternoon.

What method does SPICE use? At its core, the method you are about to learn. It is called **nodal analysis**, and it is so systematic that a computer can apply it to circuits with millions of components without any human judgement at all. For you and me, working with pencil and paper on circuits of a more modest size, it has a different appeal: it always works, it needs fewer equations than the branch-current method, and it turns circuit analysis from an art into a procedure.

In Chapter 5 we solved a two-source circuit using three unknown branch currents and three equations. By the end of this chapter you will solve the same circuit with one unknown and one equation. That is the power of choosing your unknowns wisely.

::: {.outcomes}
**By the end of this chapter you will be able to:**

- explain why node voltages make good unknowns;
- choose a reference node and label node voltages;
- write KCL equations at each node in terms of node voltages;
- handle voltage sources connected to the reference node;
- write nodal equations directly in matrix form "by inspection";
- solve the equations by elimination, Cramer's rule or software;
- use the node voltages to find any current or power, and check the result.
:::

## 10.1 The Big Idea: Node Voltages as Unknowns

In Chapter 4 we saw that once a reference node is chosen, every other node has a single voltage relative to it, and the voltage across any component is simply the difference between the voltages of the two nodes it connects. That observation is the whole basis of nodal analysis.

If we know every node voltage, we know everything. The current through any resistor follows from Ohm's law:

::: keyeq
**Current through a resistor in terms of node voltages**

I~x→y~ = {{frac|V~x~ − V~y~|R}}

The current flowing through R from node x towards node y.
:::

So instead of choosing branch currents as our unknowns, we choose **node voltages**. A circuit with n nodes has n − 1 unknown node voltages (the reference is fixed at zero), and we need n − 1 equations to find them. KCL at each non-reference node supplies exactly that many.

Why is this better than the branch-current method? Because **node voltages automatically satisfy KVL**. Walk round any loop and add up the voltage differences V~x~ − V~y~ along the way: every node voltage appears once with a plus sign and once with a minus sign, so the total is always zero. KVL is built in for free, and we only have to write KCL. In a typical circuit there are far fewer nodes than branches, so we end up with far fewer equations.

## 10.2 The Method, Step by Step

Figure 10.1 summarises the procedure. We will then apply it to a series of examples, starting simply.

![Figure 10.1 — The nodal analysis procedure.](fig/ch10_flow.svg){width=64%}

A few comments on each step:

**Step 1: Choose a reference node.** Any node will do, but some choices make life easier. The node with the most connections is a good choice, since it means many terms in the equations will have a zero in them. If the circuit already has a ground symbol, use that node. If a voltage source has one terminal at a node, choosing that node as reference often fixes the voltage at the other end directly.

**Step 2: Label the node voltages.** Give each non-reference node a name: V~1~, V~2~, V~A~, whatever you like. If a node is joined to the reference by a voltage source alone, its voltage is known immediately and is not an unknown.

**Step 3: Write KCL.** At each node with an unknown voltage, write that the sum of the currents **leaving** the node through all its branches is zero. For a resistor branch to another node, the current leaving is (V~here~ − V~there~)/R. For a current source, write its value directly, with a sign that depends on its direction: positive if it pushes current *out* of the node, negative if it pushes current *in*.

There is a lovely simplification here. **You do not need to guess current directions.** Every resistor current is written as "leaving", using (V~here~ − V~there~). When you move on to the next node, the same resistor's current is again written as leaving – from that node's point of view. The algebra takes care of the signs automatically. This one habit eliminates most of the sign errors that plague the branch-current method.

**Step 4: Solve.** You will have one equation for each unknown node voltage. Solve them by any method you like.

**Step 5: Find what you need, and check.** Calculate branch currents from node voltages, then check KCL at a node you did not use, or check a power balance.

## 10.3 A First Example: Current Sources Only

![Figure 10.2 — A two-node circuit driven by current sources. The bottom rail is the reference node.](fig/ch10_two_node.svg){width=84%}

::: example
**Worked Example 10.1 — Two nodes, two current sources**

In Figure 10.2, find the node voltages V~1~ and V~2~, and the current in each resistor.

**Step 1: Reference.** The bottom rail, which connects to four elements, marked with the ground symbol.

**Step 2: Unknowns.** V~1~ and V~2~.

**Step 3: KCL at node 1** (currents leaving):

- through R~1~ to the reference: (V~1~ − 0)/4
- through R~2~ to node 2: (V~1~ − V~2~)/4
- through the 6 A source: the source pushes 6 A *into* node 1, so the current leaving through it is −6.

{{frac|V~1~|4}} + {{frac|V~1~ − V~2~|4}} − 6 = 0

**KCL at node 2** (currents leaving):

- through R~3~: V~2~/8
- through R~2~ back to node 1: (V~2~ − V~1~)/4
- through the 1 A source, which pushes 1 A in: −1

{{frac|V~2~|8}} + {{frac|V~2~ − V~1~|4}} − 1 = 0

**Step 4: Tidy and solve.** Multiply the first equation by 4: V~1~ + V~1~ − V~2~ = 24, so

2V~1~ − V~2~ = 24    (1)

Multiply the second by 8: V~2~ + 2V~2~ − 2V~1~ = 8, so

−2V~1~ + 3V~2~ = 8    (2)

Add (1) and (2): 2V~2~ = 32, so **V~2~ = 16 V**. Substituting into (1): 2V~1~ = 24 + 16 = 40, so **V~1~ = 20 V**.

**Step 5: Currents.**

- R~1~: 20/4 = 5 A, downwards.
- R~2~: (20 − 16)/4 = 1 A, from node 1 to node 2.
- R~3~: 16/8 = 2 A, downwards.

**Check: KCL at node 2.** In: 1 A from R~2~ plus 1 A from the source = 2 A. Out: 2 A through R~3~ ✓.

**Check: power.** Source powers: 6 A × 20 V = 120 W and 1 A × 16 V = 16 W delivered, total 136 W. Resistor powers: 5² × 4 = 100 W, 1² × 4 = 4 W, 2² × 8 = 32 W, total 136 W ✓.
:::

Notice how mechanical that was. We did not have to think about which way any current flowed until the very end.

## 10.4 Writing the Equations "By Inspection"

Look again at the tidied equations of Example 10.1 before we multiplied through. Rewritten with conductances, they are:

::: eq
( {{frac|1|4}} + {{frac|1|4}} ) V~1~ − {{frac|1|4}} V~2~ = 6

−{{frac|1|4}} V~1~ + ( {{frac|1|4}} + {{frac|1|8}} ) V~2~ = 1
:::

There is a striking pattern here, which holds for every circuit made of resistors and current sources:

- The coefficient of a node's **own** voltage is the **sum of all the conductances connected to that node**.
- The coefficient of **another** node's voltage is **minus the conductance connecting the two nodes** (zero if they are not directly connected).
- The right-hand side is the **total source current flowing into the node**.

This lets us write the equations directly from the diagram, without going through KCL term by term. In matrix form:

::: keyeq
**Nodal equations by inspection**

[ G ] [ V ] = [ I ]

G~kk~ = sum of conductances at node k;   G~kj~ = −(conductance between nodes k and j);   I~k~ = source current into node k.
:::

For Example 10.1:

::: eq
{{mat|0.5,−0.25;−0.25,0.375}} {{mat|V~1~;V~2~}} = {{mat|6;1}}
:::

The **conductance matrix** G is always symmetric for circuits like this (G~12~ = G~21~), because the conductance between nodes 1 and 2 is the same as the conductance between nodes 2 and 1. Its diagonal entries are always positive and its off-diagonal entries are negative or zero. These are useful checks: if your matrix is not symmetric, you have made a mistake.

Writing equations by inspection is fast and reliable, and it is exactly how SPICE builds its equations. But it only works directly when the sources are current sources. When voltage sources appear, we need a little more thought.

## 10.5 Voltage Sources Connected to the Reference

A voltage source connected between a node and the reference node is the friendliest possible case. It fixes that node's voltage directly, so that node is no longer an unknown, and we do not write a KCL equation there at all.

![Figure 10.3 — The circuit of Worked Example 5.7, redrawn for nodal analysis. With the bottom rail as reference, the only unknown is V~A~.](fig/ch10_one_node.svg){width=66%}

::: example
**Worked Example 10.2 — Revisiting the two batteries**

Figure 10.3 is the circuit we solved in Worked Example 5.7 using three branch currents. Solve it by nodal analysis.

**Step 1: Reference.** The bottom rail.

**Step 2: Node voltages.** The top of the 10 V source is at 10 V. The top of the 5 V source is at 5 V. These are known. The only unknown is V~A~.

**Step 3: KCL at A** (currents leaving):

{{frac|V~A~ − 10|2}} + {{frac|V~A~ − 5|1}} + {{frac|V~A~|4}} = 0

**Step 4: Solve.** Multiply through by 4:

2(V~A~ − 10) + 4(V~A~ − 5) + V~A~ = 0

2V~A~ − 20 + 4V~A~ − 20 + V~A~ = 0

7V~A~ = 40,   so   V~A~ = 5.714 V

**Step 5: Currents.** Through the 2 Ω, from the 10 V node into A: (10 − 5.714)/2 = 2.143 A. Through the 1 Ω, from A to the 5 V node: (5.714 − 5)/1 = 0.714 A. Through the 4 Ω: 5.714/4 = 1.429 A.

These agree exactly with Worked Example 5.7. One equation instead of three.
:::

When a voltage source is in series with a resistor, as here, the current through that branch is simply (V~node~ − V~source~)/R, where V~source~ is the voltage at the source end: the source simply sets the "far end" voltage. Many beginners try to treat the source and resistor separately and create an extra node between them. You can do that, but there is no need: the node between them has a known voltage once you know the source value, so it adds nothing.

## 10.6 A Three-Node Circuit

Now let us take a circuit that would be tedious by reduction and very tedious by the branch-current method.

![Figure 10.4 — A three-node circuit with a voltage source and a current source.](fig/ch10_three_node.svg){width=100%}

::: example
**Worked Example 10.3 — Three unknown nodes**

In Figure 10.4, find V~1~, V~2~ and V~3~, all branch currents, and verify the power balance.

**Step 1: Reference.** The bottom rail.

**Step 2: Unknowns.** V~1~, V~2~ and V~3~. (The top of the 20 V source is at 20 V, a known value.)

**Step 3: KCL at each node.**

Node 1: {{frac|V~1~ − 20|2}} + {{frac|V~1~|4}} + {{frac|V~1~ − V~2~|4}} = 0

Node 2: {{frac|V~2~ − V~1~|4}} + {{frac|V~2~|10}} + {{frac|V~2~ − V~3~|10}} = 0

Node 3: {{frac|V~3~ − V~2~|10}} + {{frac|V~3~|5}} − 1 = 0

**Step 4: Clear the fractions.**

Node 1 (× 4): 2V~1~ − 40 + V~1~ + V~1~ − V~2~ = 0, so 4V~1~ − V~2~ = 40    (1)

Node 2 (× 20): 5V~2~ − 5V~1~ + 2V~2~ + 2V~2~ − 2V~3~ = 0, so −5V~1~ + 9V~2~ − 2V~3~ = 0    (2)

Node 3 (× 10): V~3~ − V~2~ + 2V~3~ − 10 = 0, so −V~2~ + 3V~3~ = 10    (3)

**Step 5: Solve by elimination.** From (1): V~2~ = 4V~1~ − 40. From (3): V~3~ = (10 + V~2~)/3.

Substitute both into (2). First, V~3~ = (10 + 4V~1~ − 40)/3 = (4V~1~ − 30)/3. Then

−5V~1~ + 9(4V~1~ − 40) − 2 × (4V~1~ − 30)/3 = 0

Multiply by 3 to clear the fraction:

−15V~1~ + 108V~1~ − 1080 − 8V~1~ + 60 = 0

85V~1~ = 1020,   so   **V~1~ = 12 V**

Then V~2~ = 4 × 12 − 40 = **8 V**, and V~3~ = (10 + 8)/3 = **6 V**.

**Step 6: Branch currents.**

- R~a~: (20 − 12)/2 = 4 A, from the source into node 1.
- R~b~: 12/4 = 3 A, down.
- R~c~: (12 − 8)/4 = 1 A, from node 1 to node 2.
- R~d~: 8/10 = 0.8 A, down.
- R~e~: (8 − 6)/10 = 0.2 A, from node 2 to node 3.
- R~f~: 6/5 = 1.2 A, down.

**Step 7: Check KCL at node 3.** In: 0.2 A from R~e~ + 1 A from the source = 1.2 A. Out: 1.2 A through R~f~ ✓.

**Step 8: Power balance.** The 20 V source delivers 20 × 4 = 80 W. The current source delivers 6 × 1 = 6 W. Total 86 W. Resistors: R~a~ 32 W, R~b~ 36 W, R~c~ 4 W, R~d~ 6.4 W, R~e~ 0.4 W, R~f~ 7.2 W. Total 86 W ✓.
:::

## 10.7 Solving the Equations

Writing nodal equations is usually the easy part; solving them is where arithmetic slips creep in. You have several options.

**Substitution and elimination**, as in the examples above, is fine for two or three equations, especially when some coefficients are zero.

**Cramer's rule** uses determinants and is very systematic for two or three unknowns. For two equations

::: eq
a~1~x + b~1~y = c~1~    and    a~2~x + b~2~y = c~2~
:::

the solution is

::: eq
x = {{frac|c~1~b~2~ − b~1~c~2~|a~1~b~2~ − b~1~a~2~}}     y = {{frac|a~1~c~2~ − c~1~a~2~|a~1~b~2~ − b~1~a~2~}}
:::

Appendix B explains Cramer's rule fully, including the 3 × 3 case, with worked examples.

::: example
**Worked Example 10.4 — Cramer's rule on Example 10.1**

Solve 2V~1~ − V~2~ = 24 and −2V~1~ + 3V~2~ = 8 using Cramer's rule.

**Determinant.** Δ = a~1~b~2~ − b~1~a~2~ = (2)(3) − (−1)(−2) = 6 − 2 = 4.

**V~1~** = (c~1~b~2~ − b~1~c~2~)/Δ = (24 × 3 − (−1) × 8)/4 = (72 + 8)/4 = 20 V.

**V~2~** = (a~1~c~2~ − c~1~a~2~)/Δ = (2 × 8 − 24 × (−2))/4 = (16 + 48)/4 = 16 V. ✓
:::

**Calculators and software** are the practical choice for anything larger. Most scientific calculators sold for engineering courses have a simultaneous-equation mode. Spreadsheets can invert matrices. And a few lines in a free programming language will solve the matrix form directly.

::: tip
**A Modern Tool: Solving Nodal Equations in Python**

If you have Python with the NumPy library, Example 10.3 can be solved like this, using the equations (1) to (3) in matrix form:

`import numpy as np`\
`G = np.array([[4, -1, 0], [-5, 9, -2], [0, -1, 3]])`\
`I = np.array([40, 0, 10])`\
`print(np.linalg.solve(G, I))   # prints [12. 8. 6.]`

Learn to set up the equations by hand first. Then let the computer do the arithmetic, and spend the time you save checking that the answers make physical sense.
:::

## 10.8 Practical Advice and Checks

After teaching nodal analysis for many years, I have noticed the same handful of habits separating students who get it right from those who do not.

**Draw a clean diagram first.** Redraw the circuit with the reference node as a single horizontal rail along the bottom and the other nodes clearly marked. A messy diagram produces messy equations.

**Write every resistor current as "leaving".** At node k, every resistor term is (V~k~ − V~other~)/R. Never switch conventions halfway through.

**Be careful with current-source signs.** A current source pushing current *into* the node appears as a negative term on the "leaving" side (or a positive term on the right-hand side). This is the most common sign slip in nodal analysis.

**Check the matrix.** For resistor and current-source circuits, the conductance matrix should be symmetric, with positive diagonals and negative or zero off-diagonals.

**Check the answers.** Node voltages should usually lie between the most negative and most positive source voltages in a circuit with only voltage sources. Use KCL at a node or a power balance to confirm.

::: pitfall
**Common Pitfalls in This Chapter**

- **Writing KCL at the reference node.** It is never needed; its equation is not independent.
- **Mixing "leaving" and "entering" conventions** within one equation.
- **Getting current-source signs wrong.** Into the node: negative on the leaving side.
- **Treating a source's fixed node as an unknown.** A node tied to the reference by a voltage source alone has a known voltage.
- **Forgetting the far-end voltage.** A resistor from node 1 to a 20 V source node contributes (V~1~ − 20)/R, not V~1~/R.
- **Arithmetic slips when clearing fractions.** Multiply *every* term, including constants.
:::

## Chapter Summary

- **Nodal analysis** uses node voltages as unknowns. A circuit with n nodes has n − 1 unknowns.
- Node voltages satisfy **KVL automatically**, so only KCL equations are needed.
- The current from node x to node y through R is (V~x~ − V~y~)/R.
- **Method:** choose a reference, label nodes, write KCL (sum of currents leaving = 0) at each unknown node, solve, then check.
- For resistors and current sources, equations can be written **by inspection**: [G][V] = [I], with node conductance sums on the diagonal and negative mutual conductances off it.
- A **voltage source to the reference** fixes a node voltage and removes an unknown.
- Solve by elimination, **Cramer's rule** or software, and always check with KCL or a power balance.

::: keyeq
**Key Equations**

I~x→y~ = (V~x~ − V~y~) / R     Σ I~leaving~ = 0 at each node     [G][V] = [I]
:::
