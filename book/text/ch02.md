## Systems and Their Properties

::: objectives
- Test a system for linearity, time invariance, causality, memory, invertibility and stability, and justify each answer.
- Understand why linear time-invariant (LTI) systems are completely described by a single impulse response.
- Use the impulse response to decide causality and stability at a glance.
- Combine systems in cascade, in parallel and in feedback.
- Recognise complex exponentials as the eigenfunctions of LTI systems, the idea on which the rest of the book is built.
:::

::: dropcap
A system is anything that takes a signal in and gives a signal out. An amplifier is a system; so is a loudspeaker, a car suspension, a bank account that pays interest, and a few lines of code that smooth a noisy sensor reading. The word is deliberately broad. What makes the subject manageable is that a handful of properties, each simple to state, decide which mathematical tools we are allowed to use. Get those properties right and the rest of the course opens up. Get them wrong and you will spend hours applying transform methods to systems they do not fit.
:::

We write $y(t) = T\{x(t)\}$ to mean that the system $T$ maps the input $x$ to the output $y$. It is important to understand that a system acts on the whole signal, not on a single value. When we write $y(t)$ we mean the value of the output signal at time $t$, and that value may depend on the input at many different times.

### The Six Properties

#### Linearity

A system is linear if it obeys *superposition*: if $x_1 \to y_1$ and $x_2 \to y_2$, then for any constants $a$ and $b$,
$$a x_1(t) + b x_2(t) \;\to\; a y_1(t) + b y_2(t).$$
Superposition bundles two separate ideas. *Additivity* says the response to a sum is the sum of the responses. *Homogeneity* says that scaling the input scales the output. Both must hold.

In practice there is a quick test that rules out many systems immediately. Put $a = b = 0$: a linear system must turn the zero input into the zero output. So $y(t) = 3x(t) + 2$ is not linear, however straight its graph looks. Engineers sometimes call such systems *incrementally linear*, because the *change* in output is linear in the change in input, but they are not linear in the strict sense used in this book.

To show a system *is* linear, write out the response to $a x_1 + b x_2$ in general and show that it equals $a y_1 + b y_2$. To show that it is *not*, a single counterexample suffices. Squaring, absolute values, exponentials of the input, products of the input with itself and constant offsets are the usual culprits.

#### Time invariance

A system is time-invariant if a delay at the input produces the same delay at the output: if $x(t) \to y(t)$ then $x(t - t_0) \to y(t - t_0)$ for every $t_0$. Informally, the system behaves the same today as it did yesterday.

The test needs care, and I recommend writing it in two lines every time. First, feed in the delayed input $x(t - t_0)$ and work out what comes out; call it $y_1(t)$. Second, take the original output formula and replace $t$ by $t - t_0$ everywhere; call it $y_2(t)$. If $y_1 = y_2$ for all inputs, the system is time-invariant.

::: example
**Is $y(t) = x(2t)$ time-invariant?**

*Delayed input.* Feeding in $x_d(t) = x(t - t_0)$, the system replaces its argument by $2t$, giving $y_1(t) = x_d(2t) = x(2t - t_0)$.

*Delayed output.* $y_2(t) = y(t - t_0) = x(2(t - t_0)) = x(2t - 2t_0)$.

These differ, so the system is time-varying. The intuition is that the compression acts relative to $t = 0$, which singles out one particular instant.
:::

The clues to look for are coefficients that depend explicitly on $t$ (as in $t\,x(t)$ or $x(t)\cos\omega_c t$) and any operation on the time axis other than a plain shift (scaling, reversal).

#### Causality and memory

A system is *causal* if the output at any time depends only on present and past inputs. Every physical system that runs in real time is causal, because nature cannot respond to inputs it has not yet received. Non-causal systems are perfectly respectable, though: if the whole signal has been recorded, as in image processing or offline audio editing, we can use 'future' values freely.

A system is *memoryless* if the output at each time depends only on the input at that same time. A resistor is memoryless; a capacitor is not, because its voltage depends on the entire history of current through it.

The test for causality is to look for any instant at which the output depends on a later input. For $y(t) = x(t/2)$, set $t = -2$: the output is $x(-1)$, which lies in the future. So the system is not causal, even though for positive $t$ it only looks backwards. One counterexample is enough.

#### Stability

We use the bounded-input, bounded-output (BIBO) definition: a system is stable if every bounded input produces a bounded output. To prove instability, find one bounded input whose output grows without limit. The constant input $x = 1$ and the unit step are the usual choices.

#### Invertibility

A system is invertible if distinct inputs always produce distinct outputs, so that the input can be recovered from the output. Squaring is not invertible, because $x$ and $-x$ give the same result. A delay is invertible, but its inverse is an advance, which is not causal. An inverse can therefore exist on paper while being impossible to build in real time. The same happens with stability: the inverse of $y[n] = x[n] - 3x[n-1]$ is the recursive system $w[n] = 3w[n-1] + y[n]$, which is unstable.

::: pitfall
Do not confuse 'the output depends on past values' with 'the system is not memoryless *and therefore* not causal'. Memory and causality are separate questions. A pure delay has memory and is causal; a pure advance has memory and is not causal; a system with no memory is automatically causal.
:::

### Why LTI Systems Are Special

When a system is both linear and time-invariant, something remarkable happens: a single signal tells you everything about it. Here is the argument in discrete time, where it is easiest to see.

Any sequence can be written as a sum of scaled, shifted impulses:
$$x[n] = \sum_k x[k]\,\delta[n - k].$$
This is just a formal way of saying that the sequence is made of its samples. Now let $h[n]$ be the response to $\delta[n]$. Time invariance says the response to $\delta[n - k]$ is $h[n - k]$. Linearity says the response to $x[k]\,\delta[n-k]$ is $x[k]\,h[n-k]$, and that the response to the sum is the sum of the responses. Therefore
$$y[n] = \sum_k x[k]\,h[n - k].$$
This is the *convolution sum*, and Chapter 3 is devoted to it. For our present purposes the point is that once $h$ is known, the output to any input whatever can be computed. The impulse response is a complete description of an LTI system.

This makes property testing much easier for LTI systems.

- **Causal** if and only if $h(t) = 0$ for $t < 0$ (or $h[n] = 0$ for $n < 0$).
- **Memoryless** if and only if $h = K\delta$, a pure gain.
- **Stable** if and only if $h$ is absolutely integrable (or summable):
$$\int_{-\infty}^{\infty}|h(t)|\,dt < \infty, \qquad \sum_n |h[n]| < \infty.$$

The stability condition is worth a moment's thought. If $|x| \le B$, then $|y(t)| \le B\int|h(\tau)|\,d\tau$, so absolute integrability is clearly enough. It is also necessary: if the integral diverges, the bounded input $x(t - \tau) = \operatorname{sgn} h(\tau)$ makes the output at that instant equal to $\int|h|$, which is infinite. The integral of $|h|$ is therefore the worst-case gain of the system, a useful number in its own right.

![Absolute summability decides stability. A geometric impulse response is stable when its ratio is less than one in magnitude.](figures/ch02_stability){width=96%}

::: keyidea
For an LTI system, every question about causality, memory and stability becomes a question about the impulse response. Look at $h$ first; it is almost always quicker than testing the input–output equation directly.
:::

Be careful with one subtlety. An impulse response that decays to zero is not necessarily stable. The sequence $h[n] = u[n-1]/n$ decays, yet $\sum 1/n$ diverges. It must decay *fast enough*.

### Step Response and Impulse Response

The unit step is far easier to produce in a laboratory than an impulse, so system responses are often measured with steps. Because $u(t)$ is the running integral of $\delta(t)$, the step response $s(t)$ is the running integral of the impulse response:
$$s(t) = \int_{-\infty}^{t} h(\tau)\,d\tau, \qquad h(t) = \frac{ds(t)}{dt}.$$
In discrete time the integral becomes a running sum and the derivative becomes a first difference, $h[n] = s[n] - s[n-1]$. The final value of the step response is the total area under $h$, the *DC gain*.

These relations give a second route to the response to any piecewise-constant input. Write the input as a sum of scaled, delayed steps, as you learned in Chapter 1, and add up scaled, delayed copies of $s(t)$. No integration is needed, and many examination problems are set up precisely so that this works.

### Interconnecting Systems

Real systems are built from smaller ones. Three connections cover nearly everything.

![The three basic interconnections of LTI systems.](figures/ch02_interconnect){width=92%}

In a *cascade*, the output of one system feeds the next. The overall impulse response is the convolution $h_1 * h_2$, and because convolution is commutative the order does not matter for LTI systems. (It very much matters for non-linear ones: squaring then adding one is not the same as adding one then squaring.)

In *parallel*, both systems see the same input and their outputs are added, so $h = h_1 + h_2$.

In *feedback*, the output is fed back and subtracted from the input. The time-domain description is awkward, but in the Laplace or Z domain it becomes the neat formula $G/(1 + GH)$, one of many reasons we develop those transforms in Parts III and IV.

A useful check for any interconnection is the DC gain. Cascaded gains multiply and parallel gains add, so you can predict the sum of the samples of the overall impulse response before computing it.

### Eigenfunctions: A Glimpse Ahead

Suppose we feed the complex exponential $x(t) = e^{st}$ into an LTI system. The convolution integral gives
$$y(t) = \int h(\tau)e^{s(t - \tau)}d\tau = e^{st}\underbrace{\int h(\tau)e^{-s\tau}d\tau}_{H(s)}.$$
The output is the *same* exponential, multiplied by a complex constant $H(s)$ that depends on $s$ but not on $t$. In the language of linear algebra, complex exponentials are *eigenfunctions* of every LTI system, and $H(s)$ is the corresponding eigenvalue.

This single observation explains the whole architecture of the subject. If we can write an input as a sum of complex exponentials, each one passes through the system independently, merely scaled by $H$. Fourier analysis (Part II) writes signals as sums of $e^{j\omega t}$; Laplace analysis (Part III) uses the more general $e^{st}$; and the Z-transform (Part IV) does the same with $z^n$ in discrete time.

For a real system and a real sinusoidal input, the two conjugate exponentials in $\cos\omega t$ combine to give
$$\cos(\omega t) \;\to\; |H(j\omega)|\cos\big(\omega t + \angle H(j\omega)\big).$$
A sinusoid goes in and a sinusoid of the same frequency comes out, scaled in amplitude and shifted in phase. Nothing else can happen in an LTI system: no new frequencies are created. When you see new frequencies at the output of a real amplifier, you are looking at non-linearity.

![A sinusoid through a first-order LTI system: the frequency is preserved, the amplitude and phase change.](figures/ch02_eigen){width=88%}

::: insight
Students often ask why we spend so long on abstract properties when the transforms are where the 'real' work is done. My answer is that every transform method has a licence attached, and the licence says 'LTI systems only'. If you apply a Laplace transform to $y(t) = x^2(t)$ you will get an answer, but it will be nonsense. Checking the properties first is how you make sure you are entitled to use the tools.
:::

### A Method for Classification Problems

When an examination question asks you to classify a system, work through the properties in a fixed order and write one line of justification for each.

::: strategy
1. **Linearity.** Does zero in give zero out? Is there any squaring, product of inputs, absolute value, offset or other non-linear operation? If in doubt, write out the response to $ax_1 + bx_2$.
2. **Time invariance.** Compare 'delay the input' with 'delay the output' on two separate lines. Watch for explicit $t$ or $n$ in coefficients and for scaling or reversal of the time axis.
3. **Causality.** Look for any instant at which the output uses a later input. Try a negative time if the formula involves scaling.
4. **Memory.** Does the output at $t$ use the input at any other time?
5. **Stability.** Try a constant or step input. For an LTI system, test whether $h$ is absolutely integrable or summable.
6. **Invertibility**, if asked. Look for two different inputs with the same output.
:::

The problems that follow give you plenty of practice, along with numerical work using the LTI properties, step responses, inverse systems and interconnections. The challenge problems introduce the eigenfunction idea in a concrete form, computing the response of a first-order system to a sinusoid. It is a calculation you will do hundreds of times before this book is finished.

::: remember
- Linear means superposition holds; a quick necessary test is zero in, zero out.
- Time-invariant means delaying the input simply delays the output.
- LTI systems are completely characterised by $h$.
- Causal $\Leftrightarrow h = 0$ for negative time; stable $\Leftrightarrow \int|h| < \infty$.
- $e^{st}$ in gives $H(s)e^{st}$ out.
:::
